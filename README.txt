Bumper Blast PWA. Upload this whole folder to any static HTTPS host (GitHub Pages, Netlify, Cloudflare Pages, S3+CloudFront, your own nginx).
No build step or server code needed. Open the URL once online; the service worker caches everything and the game then runs fully offline.
Install: Chrome/Edge/Android "Install app" / "Add to Home screen"; iOS Safari Share > Add to Home Screen.
